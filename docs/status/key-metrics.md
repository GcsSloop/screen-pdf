# Key Metrics

这份文档是本项目后续训练与评估的硬约束入口，避免目标在多轮实验中丢失。

## 当前硬指标

1. 点位相对于人工标注的平均偏移量 `< 0.5%`
2. `point_le_0_01_ratio > 70%`
3. 单张图片处理时间 `< 500 ms`

## 当前保留观测指标

- `point_le_0_05_ratio`
- `max_corner_le_0_03_ratio`

说明：

- 这个指标不是当前最严格的晋升门槛。
- 但它仍然保留，用于观察模型是否在拉升 strict-corner 指标时牺牲了整体可用性。

## 指标解释

### 点位偏移

- 以人工最终保存的四角点为真值。
- 建议按图像宽高归一化后计算角点误差。
- 重点看四个点的逐点误差，而不是只看模式是否命中。

### 单点精度命中

- `point_le_0_01_ratio` 已切换为逐角点统计，并恢复为当前主晋升指标。
- 只要某一个角点相对人工标注误差 `< 1%`，这个角点就计入命中。
- 最终统计的是全部角点中的命中占比，而不是逐页四点同时命中。
- 当前 round 的 checkpoint 选择与停训判断，应在 `avg_page_infer_ms <= 500 ms` 的前提下优先看这个指标。

### 最差角点命中

- `max_corner_le_0_03_ratio` 表示单张图四个点里最差的那个点，仍然 `< 3%` 的命中率。
- 这个指标仍然保留，但当前只作为观测项。
- 它用于确认 student 在拉高逐点 `< 1%` 命中率时，没有出现明显的坏角点回潮。

### 宽松命中率

- `point_le_0_05_ratio` 仍保留。
- 它统计的是单张图平均四角点误差 `< 5%` 的命中率。
- 这个指标主要用于看 strict-corner 提升时是否伴随整体可用性回退。

### 单张耗时

- 统计默认运行时链路下的整张识别耗时。
- 包含 coarse + refine + 必要的候选评分。
- 不把导出 PDF、OCR 大模型离线处理计入这个识别指标。

## 评估红线

- 不允许把测试集混入训练集。
- 不允许只用训练过的数据得出“高指标”结论。
- 如果新模型只在专项难例上涨、但全量 holdout 明显下降，则不得晋升。
- 如果命中率接近但速度明显超标，也不得作为默认运行时模型。

## 当前阶段共识

- 运行时主干优先保证泛化和速度。
- teacher 当前仍遵循“优先识别角落 T / L 结构，识别不到再用边缘做回退推算”的运行时策略。
- student 的当前训练线应优先逼近 teacher 的逐点精度和速度，而不是先优化整页最差角点。
- 特殊 bad case 的收益，不能以全局退化或过拟合窄场景为代价。
- 若连续 `3` 轮都没有把 `point_le_0_01_ratio` 提升至少 `+0.01`，则当前结构线视为进入瓶颈。
