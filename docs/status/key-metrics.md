# 当前唯一准确率指标

2026-10-17 起按用户要求，训练、选优、评估仅使用 `point_le_0_01_ratio`。完整定义见 [评估契约](evaluation-contract.md)。

单个角点在原图中的欧氏误差，除以人工四角框轴对齐包围盒的对角线，结果 `<=0.01` 计为一次命中。命中角点总数 / 全部标注角点总数即为准确率。检测失败仍计入四个角点的分母。

- checkpoint 只最大化开发验证集的这一项；平局保留较早保存件。
- 多场景汇总按角点数加权，不把项目宏平均作为第二种选优分数。按场景分别展示同一指标以定位泛化问题。
- 四点全中率、平均点位误差、最差角点误差和其他阈值命中率退出目标及验收门槛，也不用于平局或隐藏否决。
- 当前未新增固定达标线；本轮以同集比较和实测值报告结果。不能把旧四点全中率 80% 自动移为新的单点门槛。
- 时延和文件大小为运行观测，不是准确率指标，不参与 checkpoint 排序。

训练集、开发验证集与回归集保持分离。先冻结开发验证集选择的模型，再运行已查看的留出回归。已查看的留出结果不参与本轮模型、损失权重或阈值选择，也不能视为独立盲测证据。

最终交付约束：一个模型文件内包含全部学习参数和阶段计算；可包含全局与局部层级，但不能运行时再读取其他权重。新主线为 `screen_corner_single/round_xxx`。

旧报告和兼容评估函数保留原始历史字段供审计；它们不再定义当前选优规则。新主线的准确率摘要只输出这一项及页数、角点数、命中数。

当前全量基准入口：[会议场次比较](../../data/curated/collections/conference_v1/BASELINE.md)。1808 页新冻结显式人工标注按用途分别汇总，训练页混合值仅作拟合诊断；冲突 / 无效人工框先隔离，由人工校正后建立新版本，不选一份框凑入分母。
