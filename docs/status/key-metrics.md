# Key Metrics

这份文档是本项目后续训练与评估的硬约束入口，避免目标在多轮实验中丢失。

## 当前硬指标

1. 点位相对于人工标注的平均偏移量 `< 0.5%`
2. 四个点位全部相对于人工标注偏移 `< 1%` 的命中率 `> 80%`
3. 单张图片处理时间 `< 500 ms`

## 指标解释

### 点位偏移

- 以人工最终保存的四角点为真值。
- 建议按图像宽高归一化后计算角点误差。
- 重点看四个点的逐点误差，而不是只看模式是否命中。

### 四点全部命中

- 单张图只有在四个点都 `< 1%` 时才算命中。
- 这个指标比“平均误差”更能反映实际可用性。

### 单张耗时

- 统计默认运行时链路下的整张识别耗时。
- 包含 coarse + refine + 必要的候选评分。
- 不把导出 PDF、OCR 大模型离线处理计入这个识别指标。

## 评估红线

- 不允许把测试集混入训练集。
- 不允许只用训练过的数据得出“高指标”结论。
- 如果新模型只在专项难例上涨、但全量 holdout 明显下降，则不得晋升。
- 如果命中率接近但速度明显超标，也不得作为默认运行时模型。

## 当前阶段共识

- 运行时主干优先保证泛化和速度。
- 特殊 bad case 的收益，不能以全局退化为代价。
- 后续如果引入新模型头、局部 patch 或 MoE，也仍然以这三条硬指标为主。
